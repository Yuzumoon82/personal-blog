# 前端学习计划 —— 零基础到实战项目

> 已有 10 天基础（HTML/CSS/JS 语法），目标：能独立完成一个完整的前端项目。

---

## 你的起点

- ✅ HTML：标签结构、表单、语义化
- ✅ CSS：选择器、盒模型、Flex、定位
- ✅ JavaScript：变量、函数、数组、对象、DOM 操作、事件
- ❌ 还没做过完整项目
- ❌ 还没用过任何框架和工具

## 你的终点（4 周后）

能独立完成一个 **个人作品集网站**，包含：页面布局、交互效果、数据展示、响应式适配，部署到线上可访问。

---

## 第一周：巩固基础 + 第一个静态项目

### Day 1：CSS 实战强化 —— 还原一个导航栏

**学**：CSS 变量、过渡动画（transition）、伪类（:hover, :active）、box-shadow

**练**：手写一个企业官网导航栏
- Logo + 5 个菜单项 + 右侧按钮
- 鼠标悬停下拉子菜单
- 滚动后导航栏吸顶 + 背景变色
- **不查代码，自己写**

---

### Day 2：CSS 布局强化 —— 还原一个卡片列表

**学**：Grid 布局、object-fit、文本截断（text-overflow: ellipsis）

**练**：手写一个商品/文章卡片列表
- 3 列自适应网格布局（PC 3 列 → 平板 2 列 → 手机 1 列）
- 卡片含图片、标题、描述（2 行截断）、标签、日期
- 卡片悬停上浮 + 阴影效果

---

### Day 3：JavaScript DOM 实战 —— 待办事项 Todo List

**学**：localStorage 本地存储、事件委托、数组 CRUD

**练**：手写一个完整的 Todo List
- 添加、删除、标记完成、编辑
- 全部/进行中/已完成 三个筛选 tab
- 数据存 localStorage，刷新不丢失
- **这是你的第一个 JS 完整应用，全部手写，不参考**

---

### Day 4：JavaScript 异步 —— 天气预报查询页

**学**：fetch API、async/await、JSON、try/catch

**练**：手写一个天气查询页
- 输入城市名 → 调免费天气 API → 展示温度/天气/湿度/风速
- Loading 加载动画
- 错误处理（城市不存在、网络错误）
- 推荐 API：wttr.in（免费、无需注册，返回 JSON）

```javascript
// 示例：用 fetch 调天气 API
const city = 'beijing';
const response = await fetch(`https://wttr.in/${city}?format=j1`);
const data = await response.json();
console.log(data.current_condition[0].temp_C); // 当前温度
```

### Day 5-6：第一个完整项目 —— 个人作品集网站

**Day 5**：完成页面结构 + 样式
- 头部 Hero 区（头像、姓名、一句话介绍、GitHub 链接）
- 关于我（技能标签云）
- 项目展示区（3-4 个项目卡片，含截图、描述、技术栈标签、链接）
- 时间线（学习/工作经历）
- 底部联系方式

**Day 6**：添加交互 + 部署上线
- 导航平滑滚动
- 滚动到项目区域时卡片渐入动画
- 回到顶部按钮
- 用 **GitHub Pages** 免费部署，生成一个可访问的网址

**这 6 天做完，你就有了第一个能给别人看的线上作品。不要追求完美，先跑通。**

## 第二周：工程化入门 + 框架起步

### Day 7：认识 Git + Node.js

**学**：
- Git：init、add、commit、push、clone
- Node.js：是什么、npm 是什么、`npm install` 做了什么
- 用 VS Code 打开终端，跑 `node -v` 和 `npm -v` 确认安装

**练**：把第一周的作品集项目用 Git 管起来，推到 GitHub

---

### Day 8：模块化 + 打包工具概念

**学**：
- 为什么需要模块化（一个 HTML 里引 10 个 `<script>` 的痛苦）
- import/export 语法
- Vite 是什么（5 分钟理解：它帮你打包、热更新、处理兼容）

**练**：用 Vite 创建一个项目
```bash
npm create vite@latest my-project -- --template vanilla
cd my-project
npm install
npm run dev
```
把第一周的 Todo List 迁移到 Vite 项目中，拆分成多个 JS 文件用 import/export 组织。

---

### Day 9-10：Vue 3 入门（选 Vue 因为上手最快）

**Day 9 学**：
- Vue 是什么（响应式数据 + 组件化）
- 单文件组件（.vue 文件：template + script + style 在一块）
- ref、computed、v-if、v-for、v-on、v-bind

**Day 9 练**：用 Vue 3 重写 Todo List
```bash
npm create vite@latest vue-todo -- --template vue
```
把之前原生 JS 写的 Todo List 改成 Vue 组件：
- `App.vue` → 主布局
- `TodoList.vue` → 列表展示
- `TodoItem.vue` → 单条待办
- `AddTodo.vue` → 输入框 + 添加按钮

**Day 10 练**：用 Vue 3 重写天气查询页
- 拆分为 `SearchBox.vue` + `WeatherCard.vue` + `Loading.vue`
- 数据用 ref 管理

---

## 学习原则

1. **先跑通，再优化**。不要追求完美代码，先让页面能看、功能能用
2. **每天一个完整小产出**。哪怕只是一个导航栏，也要做完、能看
3. **遇到问题先自己调试 15 分钟**。console.log 是最好用的工具
4. **不抄完整代码**。看思路、自己写、卡住了再看答案
5. **GitHub 每天提交**。绿点就是你的学习轨迹
