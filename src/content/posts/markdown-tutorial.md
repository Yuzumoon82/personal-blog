## 块级元素

### 段落与换行

#### 段落

HTML 标签：`<p>`

一个或多个空行分隔段落。

代码：
```
这是第一段。

这是第二段。
```

效果：

这是第一段。

这是第二段。

#### 换行

HTML 标签：`<br />`

在行尾加**两个或更多空格**实现换行。

代码：
```
这一行不会  
换行。
```

效果：

这一行不会  
换行。

### 标题

#### Setext 风格

HTML 标签：`<h1>`, `<h2>`

用等号 `=` 表示一级标题，短横线 `-` 表示二级标题。

代码：
```
这是一级标题
=============
这是二级标题
-------------
```

#### atx 风格

HTML 标签：`<h1>` ~ `<h6>`

行首使用 1-6 个 `#`。

代码：
```
# 一级标题
## 二级标题
###### 六级标题
```

效果：

# 一级标题
## 二级标题
###### 六级标题

### 引用

HTML 标签：`<blockquote>`

使用 `>` 符号。

代码：
```
> 这是一段引用。
> 
> 这是第二段引用。
```

效果：

> 这是一段引用。
> 
> 这是第二段引用。

嵌套引用：

```
> 第一层引用
> > 嵌套引用
> 回到第一层
```

效果：

> 第一层引用
> > 嵌套引用
> 回到第一层

### 列表

#### 无序列表

HTML 标签：`<ul>`

使用 `*`、`+` 或 `-`。

代码：
```
* 红色
* 绿色
* 蓝色
```

效果：
- 红色
- 绿色
- 蓝色

#### 有序列表

HTML 标签：`<ol>`

使用数字加点。

代码：
```
1. 第一项
2. 第二项
3. 第三项
```

效果：
1. 第一项
2. 第二项
3. 第三项

#### 嵌套列表

代码：
```
* A
  * A1
  * A2
* B
```

效果：
- A
  - A1
  - A2
- B

### 代码块

HTML 标签：`<pre>`

用三个反引号包裹，可选语言标识启用语法高亮。

代码：

````
```javascript
function hello() {
  console.log("Hello World!");
}
```
````

效果：

```javascript
function hello() {
  console.log("Hello World!");
}
```

### 分隔线

HTML 标签：`<hr />`

三个或更多 `*`、`-` 或 `_`。

代码：
```
---
***
___
```

效果：

---

### 表格

HTML 标签：`<table>`

用 `|` 分隔列，`-` 分隔表头，`:` 控制对齐。

代码：
```
| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| aaa    | bbb  | ccc    |
| ddd    | eee  | fff    |
```

效果：

| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| aaa    | bbb  | ccc    |
| ddd    | eee  | fff    |

## 行内元素

### 链接

HTML 标签：`<a>`

格式：`[链接文字](URL "标题")`

代码：
```
[示例链接](https://example.com "可选标题")
```

效果：[示例链接](https://example.com "可选标题")

### 强调

HTML 标签：`<em>`, `<strong>`

代码：
```
*斜体*
**粗体**
***粗斜体***
```

效果：*斜体* **粗体** ***粗斜体***

### 行内代码

HTML 标签：`<code>`

使用反引号包裹。

代码：
```
使用 `console.log()` 函数。
```

效果：使用 `console.log()` 函数。

### 图片

HTML 标签：`<img />`

格式：`![替代文字](图片URL "可选标题")`

代码：
```
![风景](https://s2.loli.net/2024/08/20/5fszgXeOxmL3Wdv.webp)
```

效果：

![风景](https://s2.loli.net/2024/08/20/5fszgXeOxmL3Wdv.webp)

### 删除线

HTML 标签：`<del>`

代码：
```
~~这是错误的内容~~
```

效果：~~这是错误的内容~~

## 其他

### 自动链接

用尖括号包裹 URL 或邮箱。

代码：
```
<https://example.com>
<email@example.com>
```

效果：<https://example.com>

### 反斜杠转义

用 `\` 转义特殊字符。

代码：
```
\*不是斜体\*
```

效果：\*不是斜体\*

可转义字符：`\` `*` `_` `{}` `[]` `()` `#` `+` `-` `.` `!`

## 内联 HTML

Markdown 不支持的标记，可以直接写 HTML。

代码：
```
这是普通段落。

<table>
    <tr><td>表格内容</td></tr>
</table>

这是另一个段落。
```

效果：

这是普通段落。

<table>
    <tr><td>表格内容</td></tr>
</table>

这是另一个段落。
